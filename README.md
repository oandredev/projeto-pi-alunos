#### 📌 Descrição

**Projeto acadêmico** desenvolvido para a disciplina de **Projeto Integrador 3** do curso de Análise e Desenvolvimento de Sistemas no **SENAC**, com foco na construção de uma aplicação web utilizando `Angular` e `json-server` como API simulada REST.

O sistema tem como objetivo a gestão de alunos, permitindo operações completas de `CRUD`:

- Criar alunos
- Listar alunos
- Editar alunos
- Remover alunos

Cada aluno contém os seguintes `dados`:

- ID
- RA
- Nome
- CEP
- Nota 01
- Nota 02

---

#### ⚙️ Tecnologias utilizadas

- Angular 20.3.1
- json-server 1.0.0-beta.3
- TypeScript
- HTML5 / CSS3

---

#### 🧠 Objetivo do projeto

Aplicar conceitos de:

Consumo de API REST simulada
Manipulação de dados via CRUD
Componentização no Angular
Validação de formulários
Estruturação de aplicações front-end modernas

---

#### 🚀 Visão geral

O sistema simula um ambiente de gestão acadêmica simples, onde é possível administrar registros de alunos de forma dinâmica, utilizando requisições `HTTP` para interação com a API local (`json-server`).
